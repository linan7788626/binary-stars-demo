# 双星纪元 Binary Era

以**双星演化与系统参数关系**为内核的网页互动模拟，面向本科天文学专业学生。纯前端（HTML + CSS + 原生 JS，无构建工具），浏览器直接打开 `index.html` 即可。

## 运行

- 游玩：双击 `index.html`
- 冒烟测试：`node test/smoke.test.mjs`（覆盖五关卡 + 双通道的全部链路，52 项断言）

## 知识内核

韩占文《恒星物理的发展》(《物理》2025) 第 4 节《双星演化与特殊天体的形成》、Kippenhahn《Stellar Structure and Evolution》双星章、黄润乾《恒星物理》、Han et al. RAA 2020、Eggleton 1983、Peters 1964。

详细设计见 [DESIGN.md](./DESIGN.md)。

## 当前版本 v0.2 相对 v0.1 的优化

- **修正教学关键瞬间**：轨道视图中恒星改为按真实半径线性绘制(原 `sqrt(R)` 压缩导致红巨星充满洛希瓣时画面只有几像素,核心 RLOF 触发时刻不可见)
- **真实开普勒轨道动画**:用牛顿迭代解开普勒方程,真近点角随平近点角推进,近星点加速(开普勒第二定律);轨道周期通过角速度感知——短周期系统明显转得快
- **食双星几何判据修正**:`cos i · a < rSum` 而非 `sin i > rSum/a`,主序阶段默认 i=80 不再有食、膨胀为巨星后即时出现掩食
- **关卡专属速度**:此前 6 关的 `speed` 字段被忽略,现在按关卡特性应用(sun-like 100×、Algol 10×、CV/双中子星 1000×)
- **Canvas DPI 适配**:`devicePixelRatio` 缩放,Retina 屏清晰
- **质心与双轨道椭圆**:两星各自围绕质心的轨道以主星金、伴星蓝绘制,与星体卡和赫罗图图例颜色一致
- **恒显洛希瓣 + 充填警示**:洛希瓣淡描边常显,接近 90% 时高亮变红,触发 RLOF 关键瞬间一目了然
- **物质流弧形绘制**:粒子沿 L1 附近的贝塞尔曲线流动,致密伴星周围显示吸积盘
- **致密天体专属绘制**:黑洞(光子环)、中子星(脉冲光环)、白矮星(蓝白盘)差异化
- **演化阶段药丸化**:经过的阶段变蓝边框,当前阶段金色实心,终态金色描边
- **决策弹窗元数据可视化**:
  - RLOF 显示 q 与 q_crit 进度条 + 稳定/失稳判断
  - CE 同时显示 α=1.0 与 α=0.3 的能量预算,标注抛射/部分抛射/并合结局
  - 超新星显示 ΔM vs 系统总质量一半的解体线
- **Live 观测倾角滑块**:可在演化过程中实时改变 i 倾角,光变曲线即时反馈食双星状态——直观展示"倾角如何决定是否观测到食"
- **宇宙年龄进度条**:底栏显示系统年龄相对 13.8 Gyr 宇宙年龄,超过时变红
- **RLOF 转移速率 Ṁ 显示**:侧栏轨道参数在转移时实时显示 M☉/yr 数量级
- **光变曲线相位同步**:与轨道视图共享同一相位,白竖线 + 移动点直观对应"转到哪、亮多少"
- **赫罗图坐标刻度**:log Teff 与 log L 网格,主星/伴星图例,当前位置加白圈
- **性能**:UI/Hessian 重建由 60Hz 限流至 8Hz,Canvas 保持帧率
